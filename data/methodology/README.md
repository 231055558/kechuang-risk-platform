# 风险评分方法输入

本目录保存 2026-08-19 确认的最新方法输入：

- `风险分公式计算_20260819.docx`：单项风险分、NRI、熵权法和 CRITIC 两级汇总公式；
- `行业分类_20260819.xlsx`：申万三级行业分类、科创板企业数量与公司清单。

当前实现采用正文默认值 `Aₛₖ=0.5`、`α=0.5`、`β=0.5`。公式文档示例中出现的
`0.6×0.5 + 0.4×0.05` 与正文默认权重不一致，因此仅将 0.6/0.4 保留为可配置方案，
未作为运行默认值。

行业分类表备注要求将数字芯片设计与模拟芯片设计合并为“芯片”基准。半导体设备和集成
电路制造公司按股票代码归入各自基准。对应实现位于
`src/domain/industry-risk-v1/benchmark-classification.ts`。

完整性校验：

```bash
cd data/methodology
shasum -a 256 -c SHA256SUMS
```
