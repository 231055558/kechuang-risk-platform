# 科创板芯片企业风险指标数据库

## 数据范围

- 样本：10 家科创板芯片产业链代表企业。
- 基准期：2025 年度；出口管制清单截至 2026-08-18。
- 指标：完整保留原工作簿 22 项指标结构，并建立 10×22 覆盖矩阵。
- 观测：237 条，均带来源、证据摘录、置信度、判断理由和限制。

## 主要来源

1. 上海证券交易所公司概况、2025 年年度报告及公司公告检索。
2. 美国国际贸易署 Consolidated Screening List 官方 CSV。
3. 天眼查现有登录态下可见的企业页、法律诉讼页和经营风险页。
4. 用户提供的《风险指标体系8.13完整版.xlsx》，仅用于指标结构和计算口径。

天眼查部分未购买套餐，也未成功调用按次计费 API。司法和行政处罚数据只采用网页可见聚合信息，因此标为中置信度及部分覆盖。

## 置信度

- 高（>=0.85）：官方年报、交易所或政府清单直接值，或由这些输入值按明确公式计算。
- 中（0.60-0.84）：公告检索代理、天眼查聚合、地区口径近似或英文名称匹配。
- 低（<0.60）：证据不足。本版通常记为 NA，不用 0 代替未知值。

## SQLite 结构

- `companies`：企业样本及上交所核验信息。
- `indicator_catalog`：22 项指标定义和计算规则。
- `observations`：数值/文本观测、公式、来源、证据、置信度。
- `indicator_coverage`：每家企业每项指标的覆盖与缺失原因。
- `sources`：来源机构、标题、日期、URL、本地证据路径。
- `screening_hits`：官方清单名称命中明细。
- `inquiry_evidence`：问询检索原始公告明细。
- `litigation_evidence`：天眼查网页可见的 2025 年被告案件明细。
- `v_company_risk_snapshot`：每家企业一行的关键指标快照。

示例：

```sql
SELECT *
FROM v_company_risk_snapshot
ORDER BY stock_code;
```

```sql
SELECT c.stock_code, c.short_name, i.secondary_indicator,
       o.metric_name, o.numeric_value, o.unit,
       s.institution, s.url, o.confidence, o.confidence_reason
FROM observations o
JOIN companies c ON c.company_id = o.company_id
JOIN indicator_catalog i ON i.indicator_id = o.indicator_id
LEFT JOIN sources s ON s.source_id = o.source_id
WHERE c.stock_code = '688256'
ORDER BY o.indicator_id, o.metric_name;
```

## 使用限制

叙事文本、专利族前向引用、供应商国别、全量诉讼及标的额、高管关联实体风险需要持续抓取或专业数据库。当前缺失项已经保留 NA、原因和建议数据源，不能把可见案件下限或清单未命中直接解释为完整风险为零。
