# R01–R22 总数据库公开快照

本目录保存可随项目仓库分发、用于审计和重建前端派生数据的 SQLite 总数据库：

- `科创企业R01-R22风险指标总数据库_94家_公开快照_20260820.sqlite`

快照包含 94 家企业、22 项指标、956 条来源、4,321 条主观测、687 条补充事实、391 条
深搜事件和 2,068 条企业×指标覆盖记录。数字与模拟芯片设计在评分时合并为 64 家“芯片”
基准；化学制剂为 25 家，半导体设备为 3 家，集成电路制造为 2 家。

## 公开快照处理

本文件由本地完整总库生成，保留计算所需的派生事实、API调用状态、聚合数量、来源、行级
血缘和合并审计，但执行了两项公开分发处理：

1. 将 451 条天眼查付费 API 原始 `result_json` 清空；派生指标、风险数量和来源记录继续保留；
2. 将 488 个包含工作站绝对路径的文本值改写为 `external-source/` 可移植定位符。

原始本地数据库不会被脚本覆盖。重新生成公开快照：

```bash
npm run sanitize:master-sqlite -- \
  /path/to/private-master.sqlite \
  data/snapshots/科创企业R01-R22风险指标总数据库_94家_公开快照_20260820.sqlite
```

## 完整性校验

```bash
cd data/snapshots
shasum -a 256 -c SHA256SUMS
sqlite3 科创企业R01-R22风险指标总数据库_94家_公开快照_20260820.sqlite \
  'PRAGMA integrity_check;'
```

应用运行时读取 `src/data/industry/r01-r22-unified.json`，不会直接写入该 SQLite 快照。
数据仅用于风险研究与辅助研判，不构成监管认定或投资建议；第三方数据的再次分发仍应遵守
相应许可和网站条款。
