# ADR-0001：产品面向投资者，而非企业处置后台

- 状态：已接受
- 日期：2026-08-26

## 决策

产品的直接用户是投资者和研究人员。系统用于识别风险、比较同业、追溯证据、阅读资讯和形成投资研判，不承担企业内部工单、责任分配或处置闭环。

因此：

- 主导航固定为风险总览、指标分析、风险传导、风险资讯、企业对比、企业报告、投资研判、风险应对；
- 不提供事件清单、企业处置、责任人、截止日期、待处理状态和任务流；
- 风险应对以投资前核验、合同保护、持有期监测、重新评估和退出条件为对象；
- 未经金融组确认，不输出“建议买入/卖出”或收益预测；
- 企业报告是唯一承载导出职能的页面；总览只呈现最重要信息并链接到详细页面。

## 后果

旧的企业管理型组件可以保留在历史代码中，但不得由产品导航或默认路由触达。新增 DTO 不得引入 `owner`、`dueDate`、`taskStatus`、`pendingAction`。
