# KCR Excel 导入器

状态：**可读取团队黄金工作簿，并在写入任何数据前完成整表校验**

实现位置：

- `src/importers/kcr-workbook.ts`
- `scripts/import-kcr-workbook.ts`

## 使用方式

```bash
npm run import:kcr-workbook -- input.xlsx output.json
```

导入成功时，终端会显示加权指标和叙事校验项数量；`output.json` 是不含本地附件
路径的标准化中间数据。导入失败时，终端一次性列出所有可发现的问题，而不是修完一处
再暴露下一处。

## 必需工作表

导入器要求工作簿包含以下 11 张表：

1. 风险总览
2. 企业主表
3. 指标评分
4. 原始观测
5. 风险事件
6. 实体关系
7. 叙事校验
8. 证据库
9. 评分规则
10. 数据缺口
11. API调用日志

表头可以出现在前 20 行内，因此标题、说明和空行不会影响导入；核心列名必须与契约
一致，防止列移动或重命名后产生静默错位。

## 自动校验

- 缺失工作表和缺失列一次性汇总。
- 加权指标必须正好是 T01–T05、C01–C03、F01–F04、E01–E03、P01–P03。
- 不允许重复指标 ID；每项固定权重和总权重 100 都会校验。
- 风险维度必须与指标 ID 一致。
- 风险分必须位于 0–100，证据置信度必须位于 0–1。
- 完整、部分、缺失观测的覆盖系数必须分别为 1、0.75、0。
- 缺失指标不能携带 0 或其他风险分。
- 4 个叙事校验项必须完整，并明确标记为“不计分”。
- 工作簿公式不会被执行，只接受文件中已有的缓存结果。
- 证据库的“本地文件”列始终丢弃，并产生警告，避免提交个人工作站路径。
- 无法读取或损坏的 `.xlsx` 会返回明确错误，不会生成半成品 JSON。

## 已验证的真实工作簿结果

团队提供的寒武纪黄金工作簿已完成实际导入验证：

| 内容       | 数量 |
| ---------- | ---: |
| 加权指标   |   18 |
| 叙事校验项 |    4 |
| 证据记录   |    8 |
| 风险事件   |    8 |
| 实体关系   |   15 |
| 权重合计   |  100 |

导入器识别并删除了两条个人工作站本地文件路径；输出中敏感路径和凭据特征命中数为
0。原始工作簿只在临时目录中用于验证，不进入仓库。

## 与评分引擎的边界

导入器负责读取、规范化和拒绝坏数据，不负责计算总分。第 4 步评分引擎只接受导入
成功的 18 项指标输入，并重新计算总分、维度分、覆盖率、置信度和等级，绝不信任
Excel 中的合计公式。
