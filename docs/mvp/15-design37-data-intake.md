`data/raw/industry-risk/design37-deep-20260819/`。应用运行时使用脱敏派生 JSON，不返回数据方

## 评分接入策略

1. R01–R04 保留为叙事校验，不直接计权。
2. R05–R22 共 18 项全部进入候选列表。
3. 每项选择企业最新同口径数值；不同报告期不能按数据库行顺序误取旧值。
4. 每个指标在拥有数值的企业子样本内计算风险分位。
5. 企业综合分只平均该企业实际拥有的指标，缺失项不补零、不插值并从分母跳过。
6. 原公式近似值、部分代理和暂无数值必须在 API 与页面中分别标注。
7. 补充事实与 B01–B03 定义不计分，也不再出现在默认页面。

本阶段曾有14项可比数值，37家均可生成阶段性候选分，每家使用6–14项；该历史实现版本为
`IRAWC-MISSING-AWARE-2026.08-v3`，不再是当前API和页面的运行方法。

## 公开与复现边界

团队已授权把原始 SQLite、Excel 和说明文档随仓库分发，以便其他成员克隆后得到相同数据底座。
原始快照可能保留数据方的审计字段；应用、API 与图谱只使用脱敏派生合同。任何正式权重、阈值或
代理替换都必须产生新的方法版本，不能静默覆盖当前结果。
