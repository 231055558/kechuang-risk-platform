# 37 家数字芯片设计企业数据接入决策

状态：**原始快照和派生数据已建立；运行时切换与评分 V2 待后续 PR**

记录日期：2026-08-19

## 数据变化

新版范围是 37 家科创板数字芯片设计企业，不是旧 10 家芯片产业链样本的简单扩容。两个
样本仅重合澜起科技、龙芯中科、晶晨股份、寒武纪和芯原股份 5 家。旧样本中的半导体设备、
晶圆制造企业继续作为历史数据集保留。

| 内容 | 旧 10 家 | 新 37 家 |
| --- | ---: | ---: |
| 企业 | 10 | 37 |
| 指标 | 22 | 22 |
| 原始或派生观测 | 237 | 1,384 |
| 企业×指标覆盖记录 | 220 | 814 |
| 来源 | 31 | 119 |
| 问询证据 | 10 | 51 |
| 补充事实 | 0 | 205 |
| 报告可得性记录 | 0 | 37 |

新版使用 36 份 2025 年报、11 份 2026 半年报、25 份 2026 一季报，以及长鑫科技招股书
和 2026Q1 审阅数据。不同企业的最新报告期不同，因此评分必须按企业选择最新同口径观测，
不得直接取数据库中的第一条记录。

## 已确认接入策略

1. 37 家版本成为当前数字芯片设计主样本；旧 10 家版本按日期保留，不覆盖删除。
2. 三份原始文件原样保存在 `data/raw/industry-risk/design37-20260819/`。
3. 派生 JSON 删除数据提供方本机路径和报告原文摘录。
4. 单指标至少有 20 家可比企业才允许计算横截面风险百分位。
5. 缺失值不补 0；只有五项试验指标齐全的企业生成五项候选综合分。
6. 补充事实和 B01–B03 加分定义当前均不计分。

## 数据质量发现

- R07 和 R13 的指定试验度量覆盖 37 家。
- R14 的覆盖表标记 37 家可评分，但只有 31 家存在“无形资产占比变动”精确度量。
- R16 有 35 家存在经营现金流短债覆盖率；长鑫科技明确部分覆盖，龙迅股份的覆盖标记与
  实际度量不一致。
- R18 只有 20 家披露统一口径的海外收入占比。
- 当前只有 16 家同时具备 R07、R13、R14、R16、R18 五项精确度量。

程序必须以实际度量和样本量为评分准入依据，同时保留数据提供方的原始覆盖标记供审计。
这些不一致不得通过补值、改写原始 SQLite 或把未知值解释为 0 来消除。

## 新增非评分数据

`supplementary_observations` 保存资产负债率、借款规模、前五客户和前五供应商集中度等
205 条事实。它们可用于解释 R15、R17 或企业经营背景，但不能替代原指标要求的融资成本、
供应商国别或进口依赖度。

`bonus_catalog` 的 B01–B03 只有定义和上限，没有 37 家企业观测。本期仅作为未启用的方法
候选展示，不进入风险分、排名或覆盖率。

## 公开与复现边界

原始 SQLite 和 Excel 保留 116 条数据提供方本机证据路径及官方报告摘录，这是团队明确
授权的原始审计快照。应用和 API 只使用脱敏派生 JSON，不返回本机路径或原始长摘录。
