  `Ocean281818/2026-kechuang-fengxian-shibie_public`。
- MVP 代码只在 `mvp/2026-08-21` 分支推进，不直接修改 `main`。
- 群聊、会议转写、凭据、私密附件和付费 API 原始响应不得进入 Git。
- 只有项目有权再次分发、且已经脱敏整理的数据，才能成为测试夹具或演示数据。

`.env.example`。
