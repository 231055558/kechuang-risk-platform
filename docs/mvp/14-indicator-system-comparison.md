# KCR 18+4 与毛同学 R01–R22 指标体系对比

状态：**R01–R22 已成为默认风险研判主契约；KCR-2026.08-v1 仅保留历史复算兼容**

记录日期：2026-08-19

## 结论

两套体系不是完全不同的指标体系。它们都包含 22 项指标、4 项叙事校验、18 项客观风险候选
和 5 个风险维度。KCR 版本主要对 R01–R22 进行了工程编号、语义扩写和固定权重配置。

真正无法一一对应的差异只有一组：毛同学的 R16“经营现金流与短期偿债压力”没有进入旧
KCR；旧 KCR 额外加入 F04“存货与预付款占用（模型补充项）”。后续不得把二者静默解释为
同一个指标。

## 总体区别

| 对比项   | KCR-2026.08-v1                   | 毛同学 R01–R22                                    |
| -------- | -------------------------------- | ------------------------------------------------- |
| 来源     | 2026-08-13 寒武纪工作簿候选方法  | 团队提供的行业 SQLite 数据库                      |
| 当前角色 | 寒武纪黄金样例与历史演示兼容     | 多企业行业数据的主契约                            |
| 编号     | T/C/F/E/P/N 表示维度             | R01–R22 稳定编号                                  |
| 权重     | 18 项固定专家权重合计 100        | 数据库未提供可宣布为正式总分的完整固定权重        |
| 评分含义 | 方法规定有风险分和证据时如何汇总 | 数据标记原始观测是否具备同业可比性                |
| 汇总     | 固定权重复算寒武纪 35.6 候选基线 | 现有项横截面百分位等权平均，不是正式 R05–R22 总分 |
| 缺失     | 不补 0，按有效权重归一           | 不补 0、不插值，保留缺失原因                      |

“有固定权重”不等于“已有足够原始数据自动算分”。旧 KCR 的寒武纪输入已经携带 18 项
工作簿风险分，后端负责校验和加权复算；行业库则必须从多家公司同口径原始值计算风险分。

## 结论归属

| 内容                                     | 归属与边界                           |
| ---------------------------------------- | ------------------------------------ |
| R01–R22 定义、公式、来源和覆盖标记       | 毛同学数据                           |
| 企业原始观测、来源、置信度和限制         | 毛同学数据                           |
| 寒武纪 18 项风险分、固定权重和 35.6 基线 | 寒武纪团队工作簿候选结果             |
| T/C/F/E/P/N 编号                         | 工程适配                             |
| F04 存货与预付款占用                     | 工作簿/模型补充，不属于 R01–R22      |
| 横截面百分位与现有项等权平均             | 后端 MVP 候选方法，不是数据方正式总分 |
| 熵权、CRITIC 与行业风险 0.5              | V2 历史试验，已退出当前 API 与页面     |

## 后续约束

1. 新的行业数据、API 和页面统一使用 R01–R22 编号。
2. KCR-2026.08-v1 保留版本号和寒武纪复算能力，但不再作为扩样主契约。
3. R16 必须作为独立指标保留；F04 只能作为不计分补充事实，除非团队正式更新指标体系。
4. 指标定义与评分资格分离：定义存在不代表数据已满足评分条件。
5. 任何权重、阈值或缺失处理变更都必须生成新方法版本，不得覆盖历史结果。

## 默认页面迁移

2026-08-19 起，“风险研判”默认页面不再请求或展示寒武纪 KCR V3 的 35.6 分、18 项固定
权重、旧雷达图、旧知识图谱、情景预设和处置任务。侧栏摘要与页面说明统一改为 R01–R22
行业主契约。KCR 导入器、评分器和黄金样例测试继续保留，用于审计历史结果，不参与当前
37 家行业工作台的运行时展示。
