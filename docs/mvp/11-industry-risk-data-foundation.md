## 数据边界

当前运行样本为 37 家科创板数字芯片设计企业，报告期覆盖 2025 年报至各企业最新可得的
2026Q1/2026H1，数据截止 2026-08-19。脱敏公开夹具保存：

- 37 家企业；
- 22 项指标定义；
- 1,384 条原始或派生观测；
- 814 条企业×指标覆盖记录；
- 119 个来源；
- 官方清单命中、问询和经脱敏的诉讼派生事实。

R01–R04 是叙事校验项，R05–R22 是客观评分候选项。当前只有 R07、R13、R14、R16、R18
进入横截面评分试验；五项实际可比样本量为 37、37、31、35、20。其他指标仍进入数据库和
页面，但不会因缺失而补 0。旧 10 家产业链夹具保留为历史版本。

## 本地导入

```bash
npm run import:industry-risk -- input.sqlite output.json
```

仓库现已按团队授权保存固定原始输入快照。可用下面的实际路径重建派生夹具：

```bash
npm run import:industry-risk -- \
  data/raw/科创板芯片企业风险指标数据库.sqlite \
  src/data/industry/semiconductor-risk-pilot.json
```

导入器以只读方式打开 SQLite，删除派生 JSON 中的本机路径和原始证据摘录，再执行整表校验。
应用运行时只读取派生 JSON，不依赖 SQLite 服务；原始 SQLite 保留在 `data/raw/` 供审计和重建。
文件完整性由 `data/raw/SHA256SUMS` 校验。

## 后续计算边界

本步骤只建立可靠数据底座，不在导入时计算风险分。后续评分引擎负责：

1. 选择同业同口径观测；
2. 统一风险方向并计算行业内风险百分位；
3. 应用有版本的方法计算 0–100 单指标风险分；
4. 独立报告样本量、证据覆盖、缺失和方法版本。
