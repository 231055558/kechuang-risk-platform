# R01–R22 行业风险数据底座

状态：**毛同学的 R01–R22 已成为行业样本主数据契约；旧 KCR 18+4 仅保留兼容**

## 数据边界

当前试验样本为 10 家科创板芯片产业链企业，基准期以 2025 年度为主，出口管制清单截至
2026-08-18。脱敏公开夹具保存：

- 10 家企业；
- 22 项指标定义；
- 237 条原始或派生观测；
- 220 条企业×指标覆盖记录；
- 31 个来源；
- 官方清单命中、问询和经脱敏的诉讼派生事实。

R01–R04 是叙事校验项，R05–R22 是客观评分候选项。当前只有 R07、R13、R14、R16、R18
在全部 10 家企业上被数据提供方标记为可评分。其他指标仍进入数据库和页面，但不会因缺失
而补 0。

## 本地导入

```bash
npm run import:industry-risk -- input.sqlite output.json
```

导入器以只读方式打开 SQLite，删除本机路径和原始证据摘录，再执行整表校验。公开仓库只
保存脱敏派生夹具，不提交团队原始 SQLite、iFinD 文件、天眼查页面数据、PDF 或工作站
路径。

## 后续计算边界

本步骤只建立可靠数据底座，不在导入时计算风险分。后续评分引擎负责：

1. 选择同业同口径观测；
2. 统一风险方向并计算行业内风险百分位；
3. 应用有版本的方法计算 0–100 单指标风险分；
4. 独立报告样本量、证据覆盖、缺失和方法版本。
