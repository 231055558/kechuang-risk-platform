# KCR V3 指标与证据下钻

状态：**寒武纪 5 个风险维度已接通 18 项指标和 8 条团队工作簿证据，等待前端 Review**

## 用户链路

在风险研判首页点击任一维度卡片，即可打开该维度的证据抽屉：

1. 先查看维度分、风险等级、固定权重、证据覆盖率和置信度；
2. 展开指标，查看风险分、总分贡献、覆盖系数、工作簿评分依据和公式轨迹；
3. 继续查看证据标题、来源类型、发布日期、引用位置、原文链接和支持强度；
4. 推断证据必须展示推断依据，背景材料明确标注为不能单独满足评分准入。

## 数据边界

- 18 项指标评分、理由、权重和证据引用均来自团队工作簿脱敏快照；
- 前端只展示后端 V3 引擎的复算结果，不在浏览器重新计算或改写分数；
- API 新增返回 8 条证据目录，但不提交本地文件路径、私密附件或商业 API 原始响应；
- 证据链接必须是 HTTP(S) URL 或空值，客户端也会拒绝不安全链接；
- 本步骤没有实时抓取网页，也没有补造工作簿之外的证据。

## 本步骤暂不包含

- 红旗事件到关系传播路径的交互下钻；
- 关系图、情景对比和 V3 报告导出；
- 其他企业的 KCR V3 工作簿数据。
