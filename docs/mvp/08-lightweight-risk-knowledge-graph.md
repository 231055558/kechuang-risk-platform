# 第 8 步：轻量风险知识图谱

## 本次交付

寒武纪 KCR V3 评估页已增加一张可交互的轻量风险知识图谱，完整图谱由评分 API
响应实时构建，包含：

- 1 个企业节点；
- 5 个风险维度节点；
- 18 个固定权重指标节点；
- 2 个红旗事件节点；
- 8 个来源证据节点；
- 52 条结构、证据、事件与传播关系。

页面默认聚焦分值最高的风险维度。用户可切换五个维度，并点击企业、维度、指标、
事件或证据节点查看侧栏说明；维度和指标节点可继续打开第 7 步的完整证据下钻。

## 数据与推断边界

- 企业、维度、指标、红旗和证据节点全部来自现有 KCR V3 评分响应；
- 直接、推断和背景证据沿用团队工作簿的 `supportStrength`，前端不重新分类；
- 事件—指标、事件—证据关系来自评分输入中已记录的引用，不表述为新增因果判断；
- 仅展示评分引擎判定为有效且属于红旗事件的传播路径；
- 关系图、红旗事件与传播风险均不改写 35.6 分客观基线；
- 当前材料没有可核验的独立专利、供应商和人员实体关系，因此本次没有补造这些实体节点。

## 可视化验收

1. 打开寒武纪评估总览，确认客观基线下方显示“轻量风险知识图谱”；
2. 依次切换五个维度，确认指标、证据和相关红旗节点随维度变化；
3. 点击不同类型节点，确认右侧审计卡显示对应评分或来源信息；
4. 点击维度或指标卡中的证据链按钮，确认可打开第 7 步证据抽屉；
5. 核对图例：直接证据为实线，推断证据为虚线，背景核验为点线，传播路径单独标识。
