# 企业材料目录与行业风险知识图谱

状态：**学生企业材料已完成脱敏编目；毛同学数据与材料目录已进入统一关系图**

## 学生材料接入边界

本地材料共覆盖 7 家企业、84 份文件，其中包括 75 个 Excel 工作簿、8 份 PDF 和 1 个归档文件。
导入器逐个读取 75 个工作簿并统计工作表与非空行，共识别 5,895 行派生结构元数据。

应用运行时的材料目录仅暴露以下派生元数据：

- 企业稳定编号；
- 材料类别与文件格式；
- 工作表数量和非空行数；
- 来源类别、再分发边界和接入状态。

页面和 API 不暴露本机路径、单元格值或 PDF 原文。团队已另行授权将 84 份固定原始材料快照
保存在 `data/raw/企业信息/`，便于其他成员克隆后复核和继续开发。原始文件随仓库存在不等于
已经完成字段接入：所有材料当前仍标记为 `cataloged-not-ingested`，在建立字段映射和复核规则前
不进入风险分。

可从原始目录重建材料目录：

```bash
npm run import:enterprise-evidence -- \
  data/raw/企业信息 \
  src/data/industry/enterprise-evidence-catalog.json
```

## 完整行业图谱

`KCR-INDUSTRY-GRAPH-2026.08-v1` 统一组织：

- 10 家可评分行业企业和 6 家证据目录企业；
- 7 个产业链环节、22 项 R01–R22 指标和 31 个已脱敏来源；
- 48 个出口管制、问询与诉讼派生事件；
- 84 份学生材料的脱敏元数据节点；
- 526 条产业链、覆盖矩阵、指标来源、事件关联和材料归属关系。

前端默认提供完整网络，同时支持按企业聚焦。节点颜色按实体类别与候选风险语义区分；点击节点后展示完整名称、
解释和邻接关系，不再使用无法识别的 `T…`、`S…` 缩写。图谱关系只表示样本归类、数据覆盖、来源或材料归属，
不自动宣称因果关系。
