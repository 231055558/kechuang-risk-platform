# KCR V3 前端总览

状态：**历史实现；已从默认风险研判首页下线，仅保留复算兼容**

> 当前默认方法见 `12-industry-risk-scoring-methods.md`。以下内容只记录曾经交付的寒武纪黄金样例，

## 本地查看

```bash
npm run dev
```

打开 `http://127.0.0.1:5173/`，在左侧企业选择器中选择“寒武纪”。页面会从本地
评分 API 加载并展示：

- 35.6 客观风险基线及中风险等级；
- 95% 证据覆盖率与 88.75% 证据置信度；
- 五维风险图及每个维度的精确分值；
- BIS 实体清单和重大劳动争议两条红旗；
- 团队工作簿、程序复算和工程默认之间的来源边界。

“方法与来源”抽屉明确说明方法仍是候选版，以及 4 项待团队确认的工程默认。寒武纪
页面不会继续显示旧六维口径，也不会误导出旧版报告。其他企业仍保持旧页面可运行，
直到获得相应的 KCR V3 数据快照。
