# 行业风险评分方法版本

状态：**37 家缺失容忍横截面 V3 可运行；候选分不是正式评级**

## `IRAWC-MISSING-AWARE-2026.08-v3`

当前方法以毛同学的 R01–R22 为唯一运行时指标体系：

- R01–R04 是数据方定义的叙事校验项，不直接计入客观综合分；
- R05–R22 共 18 项全部进入评分候选范围；
- 每项选择企业最近时点的指定数值，在拥有该数值的企业子样本内计算风险分位；
- 高值高风险指标直接使用同业百分位，低值高风险指标先反向再计算百分位；
- 指标候选分等于风险分位乘以 100，不再混入没有数据依据的“行业风险 0.5”占位值；
- 单家公司只汇总自己实际拥有的指标，缺失项不补零、不插值，并从分母跳过；
- 可用项采用等权平均，接口同时返回 `availableIndicatorCount / 18` 和覆盖率；
- 结果统一标为 MVP 候选基线，不是数据方给出的正式评级或权重结论。

公式如下：

```text
indicatorRiskScore(i, c) = 100 × peerRiskPercentile(i, c)
companyCandidateScore(c) = mean(indicatorRiskScore(i, c) for available i)
coverage(c) = availableIndicatorCount(c) / 18
```

## 当前可计算边界

深搜增强版使 14 项拥有至少 2 家可比数值：R05、R06、R07、R08、R10、R11、R12、
R13、R14、R15、R16、R18、R19、R22。R09、R17、R20、R21 仍没有统一数值，保留在
18 项列表中并显示“暂无统一数值”。

37 家企业均可从自身现有指标生成候选分，每家实际使用 6–14 项。寒武纪使用 13/18 项；
长鑫科技使用 6/18 项。不同覆盖率的候选分可用于 MVP 探索，但比较时必须同时查看覆盖率。

## 原公式值与代理值

当前 14 项可计算度量不全是毛同学原公式的完整实现：

- 原公式近似值：R06、R07、R11、R13、R14、R16、R18；
- 部分代理：R05 授权专利数、R08 延期事件数、R10 可见处罚累计数、R12 重大诉讼披露件数、
  R15 期末债务融资成本代理、R19 美国综合筛查清单命中数、R22 核心技术人员离职事件数；
- 暂无统一数值：R09、R17、R20、R21。

页面和 API 必须逐项返回 `basis` 与限制说明，禁止把代理值写成原公式已经完成。

## 为什么停止 V2

V2 只计算 R07、R13、R14、R16、R18，并要求一家公司五项齐全后才能生成熵权/CRITIC
候选分，导致只有 16 家有综合分，也浪费了深搜版新补的其他指标。V3 按用户确认改为全指标、
缺失容忍和可用项重算分母；V2 的熵权、CRITIC 与行业 0.5 占位值不再进入当前 API 和页面。
