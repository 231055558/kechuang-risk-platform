# 四样本叙事风险数据可行性评估

评估日期：2026-08-25  
样本：寒武纪、燧原科技、华微电子（600360，吉林华微）、恒瑞医药  
用途：首轮数据管线试点与指标可计算性验证，不作为四家公司风险高低的预设结论

## 结论

这组样本适合启动采集，作为“数据管线试点”的综合可行性为 **4/5（较高）**；但只有 4 家公司，不能作为模型科学有效性的统计证明。它可以检验：

1. 公司自身、第三方、财务、市场关注和事件标签能否按时点对齐；
2. 叙事热度、叙事偏差、高承诺—兑现差和叙事不稳定等指标能否稳定计算；
3. 模型能否把行业热度与公司特异风险区分开；
4. 是否存在信息泄漏、语料重复、规模偏差和跨行业不可比问题。

若要验证区分能力、估计阈值或学习权重，建议第二阶段扩展至至少 12–20 家公司、4–6 个监管确认风险正样本，并保留 3–5 年或 8–12 个季度的滚动观测。

## 平台现状

当前统一运行库中，四家公司只有寒武纪已经作为精确实体接入。燧原科技、吉林华微电子和恒瑞医药需要新建实体、别名、来源和观测记录。现有库中的“成都华微电子科技股份有限公司”不是本次的吉林华微电子，不能混用。

因此首轮工作应理解为：**一家复用，三家新接入**。本次没有直接改写生产评分数据，避免在字段和时间边界尚未确认前污染现有结果。

## 必须修正的时间设计

### 1. 燧原科技：冻结到 8 月 23 日末更稳妥

招股意向书于 2026-08-25 正式披露，但 8 月 24 日晚间已经出现包含招股数据的新闻。如果将“2026-08-24 全天”纳入预测特征，会把招股书暴露的财务和风险信息倒灌进模型。

建议：

- 主预测截止：`2026-08-23 23:59:59 Asia/Shanghai`；
- 灵敏度分析截止：`2026-08-24 18:00:00 Asia/Shanghai`；
- 2026-08-25 招股意向书、财务和风险因素：`feature_eligible=false`，只作验证标签。

### 2. 华微电子：使用双时间窗

2024-05-15 虽早于 5 月 16 日立案，但 2023 年报的非标审计意见和股票风险警示已经公开。只使用 5 月 15 日作为截止日，会使任务退化为识别“已明牌风险”。

建议同时保留：

- 盲测窗口：`2024-04-29 23:59:59`，检验模型能否在年报和非标审计意见公开前预警；
- 公开红旗确认窗口：`2024-05-15 23:59:59`，检验模型能否吸收已公开监管/审计线索；
- 首次事件：`2024-05-16` 收到立案告知；
- 最终标签：2025 年证监局行政处罚。

预测期原始年报和问询回复即使后来被证明存在问题，也应保留原样；更正、处罚和事后查明事实存入 `label_evidence`，不能替换历史输入。

## 建议的采集契约

每条文本至少保留以下字段：

| 字段 | 含义 |
|---|---|
| `entity_id` / `entity_alias` | 精确实体及命中的别名；防止吉林华微与成都华微、晶华微混淆 |
| `published_at` | 文本标注发布时间 |
| `available_at` | 研究者在公开渠道最早可获得的时间，用于防泄漏 |
| `source_type` | 公告、年报、官网、媒体、研报、论坛、搜索指数、监管文件 |
| `author_role` | 公司自身、承销/券商、媒体、用户、监管者 |
| `canonical_url` / `content_hash` | 去重键，解决转载和同稿多发 |
| `title` / `body` | 原始标题与正文，保留快照或可审计引用 |
| `claim_type` / `claim_target` / `claim_horizon` | 技术、产品、客户、收入、量产、临床、获批等承诺及期限 |
| `evidence_type` / `realized_at` | 财务、订单、获批、临床里程碑等兑现证据 |
| `feature_eligible` | 截止日前是否可进入预测特征 |
| `label_type` / `label_confirmed_at` | 立案、处罚、非标审计、风险警示等事后标签 |

注意力数据不能直接使用搜索页面显示的“约 N 条结果”。应抓取明细 URL，按标准化标题、正文哈希和规范 URL 去重，再按日或季度聚合。百度指数若不能稳定自动导出，第一轮可先用新闻明细数、股吧有效帖数和换手率构造可复核代理量，百度指数作为增强源而非必需源。

## 指标可计算性

1. **热度—基本面背离**：寒武纪、华微、恒瑞可计算完整版本；燧原只能计算不含行情/统一股吧口径的降级版本。同比增速先缩尾，再在各自行业内标准化，不能把芯片和创新药原始数直接比较。
2. **自身—第三方叙事偏差**：四家公司都可计算，是本组最稳的共同指标。燧原尤其适合，但应按文本数量做置信区间或自助法，避免小样本被单篇报道支配。
3. **高承诺—低兑现**：寒武纪和燧原可使用量产、客户、生态、算力、国产替代等词典；恒瑞需使用临床阶段、NDA/BLA、获批、医保、License-out 和里程碑付款词典；华微需加入资金占用、关联交易、问询回复和审计意见。
4. **叙事不稳定/转向**：四家公司都可按季度计算，但只能与同一公司历史或同业比较。监管文件和事后处罚不得进入预测期主题分布。

首轮输出建议保留 4 个分指标、数据覆盖率和置信度，不急于合成单一“叙事风险总分”。权重和阈值应在扩样后再定。

## 来源覆盖快照

- 公司自身语料：寒武纪官网有年度归档；燧原官网新闻可回溯至至少 2021 年；吉林华微官网新闻页显示 323 条、54 页；恒瑞官网新闻具有多年动态列表。
- 第三方语料：东方财富新闻检索的界面估计量约为寒武纪 9,108、燧原科技 33、华微电子 213、恒瑞医药 3,003。该数值仅用于判断量级，不可直接作为模型变量。
- 燧原上市前没有与上市公司等价的独立行情和稳定股吧入口，相关讨论散落在其他股票论坛，必须做实体识别后再计数。
- 当前平台已有寒武纪的行业库、公告和新闻证据，可复用；另外三家需新增采集连接器或离线导入。

## 最终执行建议

可以立刻进入首轮采集，但对项目命名应保持准确：

- 阶段 0：四样本数据管线试点；
- 阶段 1：冻结时点、去重、实体消歧、四个分指标可计算性；
- 阶段 2：扩展同业和风险正样本，做阈值、显著性、稳健性与消融检验；
- 阶段 3：只有通过样本外检验后，才把指标作为正式风险评估输入。

这组四样本目前足以回答“数据能否收、指标能否算”，还不足以回答“指标是否能稳定预测风险”。
